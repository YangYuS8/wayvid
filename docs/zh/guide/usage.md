# 使用指南

本页说明 LWE 的主要工作流。

## 本地库

本地库是日常使用本地壁纸内容的入口。你可以在这里查看已识别壁纸、检查兼容性信息，并把受支持的项目应用到显示器。

Library 卡片会显示内容类型、兼容性等级和播放资格。视频项目使用已验证的运行时路径。场景项目逐项评估：通过实验性渲染器资源验证的项目会标记为**实验性场景**；存在阻断的项目仍可浏览，但禁用播放。打开详情面板可查看阻断播放的资源或特性。

典型本地库流程：

1. 打开**本地库**。
2. 选择一张壁纸。
3. 查看元数据和兼容性详情。
4. 将其应用到显示器，或清除当前分配。

应用、清除或恢复桌面分配后，LWE 会尽可能刷新当前选中的 Library 详情，使已分配显示器标签与 Desktop 页面保持一致。如果刷新失败，已填充的详情视图会继续保留，并以内联方式显示错误。

## 创意工坊

创意工坊功能围绕发现和获取编排设计。LWE 帮助用户查找 Wallpaper Engine 内容，理解它在 Linux 上是否可用，并把可识别内容纳入本地工作流。

创意工坊浏览需要在**设置**中配置 Steam Web API 密钥。订阅、下载和账号内容同步仍可能由 Steam 负责。

在线创意工坊结果仅用于发现内容。某个结果能在 LWE 中看到，并不表示它已经同步到本机；LWE 也不会直接下载创意工坊内容。请把**在 Steam 中打开**视为获取和订阅交接，然后在 Steam 完成同步后刷新本地创意工坊内容。

搜索结果卡片会标记推断出的运行时期望。视频播放需要本地同步和可用的桌面运行环境。场景结果需要验证本地资源后才能判断播放资格；在线结果不能作为兼容性测试。网页和应用程序结果仍不在当前运行时范围内。

即使筛选后只剩一个或两个结果，创意工坊搜索卡片也会保持受控宽度，使少量结果列表与正常浏览页保持一致的视觉比例。

缺少 Steam Web API 密钥时，创意工坊搜索会引导你回到**设置**。设置也会尽可能区分常见 Steam 集成状态：未检测到 Steam、检测到 Steam 但缺少 Wallpaper Engine 创意工坊内容、Wallpaper Engine 可用但尚未同步本地创意工坊项目，以及本地创意工坊内容可用。

## 兼容性等级

请把 LWE 显示的兼容性信息作为判断壁纸当前是否可用的依据。

LWE 的产品模型识别常见 Wallpaper Engine 内容类型：

- `video`：主要运行时目标，已在 Wayland 与 `niri` 上验证；
- `scene`：识别本地项目，并按实验性 2D 渲染器逐项验证；桌面验收仅覆盖下方记录的具体样本与环境，不代表完整支持场景；
- `web`：用于报告识别，不是首发运行时目标。

如果应用显示某项目不支持或处于降级状态，不应假定重新安装包即可修复。它可能超出了当前运行时范围。

### 实验性场景验证

场景读取器可读取打包资源和未打包的项目目录。项目引用内置材质或特效时，会使用本机原版 Wallpaper Engine 的资源。LWE 不分发这些原版资源。

渲染器验证具有显式固定正交尺寸的 2D 图片图层、静态变换与颜色、受支持的纹理格式，以及范围有限的特效管线。保存的 eye 与 center 的 X/Y 必须相同，朝向负 Z 且使用默认 up，不含活动 `camera.paths`（字段缺失或空数组），且未启用自动投影。保存的 X/Y 可以非零：在这个受限分支中，LWE 按原程序静态加载路径的观察重置为规范相机，不把保存坐标作为图层平移。倾斜或反向相机、非默认 up、相机路径、自动投影、运动/视差，以及图层/模型的 `parent` 绑定仍会阻断。

旧式图片材质子集包含 `genericimage`、双纹理和四纹理两种 `flowimage`、`swayimage` 与 `flag`。图层尺寸可来自图片模型的 `width`/`height`，较小图层保留作者的缩放和位置。这些材质使用项目原始着色器资源、受支持的重复/边缘限制纹理标志、带 padding 的图片边界和时间动画。声明式 `usershadervalues` 映射把经验证的项目属性连接到材质 uniform，包含颜色选择；用户映射与材质常量指向同一值时，尚不宣称覆盖优先级与原引擎精确一致。

特效子集包含 Shake、Shine、WaterRipple、Iris、Scroll、Pulse 和有界的项目自带特效 pass，以及 sprite/rope 粒子、事件子系统和四 pass LDR 泛光。粒子可使用经验证的单图片 `TEXS0002` 精灵图集，支持序列/随机帧选择与序列帧插值，以及有界的平面湍流、透明度/尺寸振荡和角运动；噪声与随机行为尚未核对原引擎。内嵌音频支持每层一条 FLAC 循环音轨，保留作者音量。精确声明式 `user`/`value` 绑定使用经验证的 bool、slider、color 和 combo 选择，combo 条件相等可控制可见性。项目/显示器选择经过验证并与分配一起保存。未知绑定/组件形状、缺失或错误声明、文字、3D 模型、骨骼动画、带时长或多图片 TEXS、视频纹理和 HDR 继续阻断。

受限纯标量 SceneScript 在 CPU 准备阶段由声明控件计算属性。另一条有界 worker 路径现已实现 `init`、`update`、`applyUserProperties`、有限 `Vec3`/图层访问，以及初始化期间的图片模型 `createLayer(path)`；真实 64 档 `average` 音频缓冲可驱动音频条。未知 API、导入、通用动态访问、时钟/时间 API、随机数及更广泛交互仍阻断。原始 Yakuza 的四个背景 × 音频条开关已通过 CPU 准备；五组完整离屏 GPU 用例及真实 Library/Desktop 控件/保存/失败/重启/重置流程已在记录的单输出 `niri`/AMD 680M 桌面通过，自有静音音频输出的真实 monitor 采集 → 64 档 FFT → 原始脚本 → 离屏音频条像素也已独立通过，未证明用户当前音乐/视频路由或 Windows 一致性，详见 [Yakuza 开发记录](../contributing/guide.md#yakuza-扩展-2026-10-12)。

`perspective:true` 图片仅在固定正交投影、Z 坐标为零、无 X/Y 旋转且无相机运动/视差时进入共面子集；它与平面变换等价属于数学推断，原引擎逐层映射和视觉一致性尚未证实。

静态图片路径支持 `genericimage2` 的缺省 VERSION 旧版 Brightness/Alpha 接口及显式 VERSION 1/2 Color4 接口，特效后合成使用 VERSION 2 的 0/30/31 模式；保留项目着色器、特效顺序，以及 fullscreen/passthrough 图层使用的完整画面输入。Pulse 和兼容的项目特效可读取真实桌面输出音频，按每个立体声通道提供十六档从低频到高频的归一化频谱。采集当前输出的 monitor，不读取麦克风；输出采集暂不可用时提供静音。归一化和分频尚未与 Windows Wallpaper Engine 对齐。

混合样本 `3659880761` 现在通过原始包准备与有限 engine-only 桌面 Probe，保留作者默认配置：6 个可见粒子根系统加 5 个子系统、所有活动特效和 LDR 泛光。第七个 Reactive 根系统由作者设为 `visible:false`，保持隐藏；启用其音频响应仍阻断。这是有界路径的默认播放能力，不代表完整粒子/FFT 支持或原版视觉一致。

原创意工坊项目 [2.5D Space（`2903458386`）](https://steamcommunity.com/sharedfiles/filedetails/?id=2903458386) 已保留全部十个图片图层、十一个特效和二十四个 pass，包括 Scroll、音频 Pulse/色差及项目自带的泛光链。在记录的单输出 `niri`/680M 机器上，真实 LWE Library/Desktop 应用、全部二十个作者控件编辑、保存失败回滚/重试、新进程恢复、默认值重置、Settings 更新和有限全屏恢复均通过。首轮引擎 Probe 另通过暂停/恢复与清除。这是新增四项发现样本中首项通过有限验收的项目；该快照中另外三项阻断，Yakuza 现已有独立有限 CPU/GPU/原生 UI 记录，另通过真实私有输出音频到 GPU 的检查。测量值与验证边界见 [Space 验收记录](../contributing/guide.md#space-2026-10-10)。

官方内置项目 Deep Space、Beach 和 Eagle Flag 分别通过原始资源 CPU 准备，以及有限的 engine-only 桌面播放、暂停/恢复与清除检查；已复核的截图确认可见动画。它们是本机十四个官方项目中的三个，与下方已下载 Workshop 样本计数独立。本轮没有把这些 builtins 加入本地库，也不代表其原生 UI、分配持久化、原引擎视觉 A/B 或日用验收完成。

兼容性面板报告首次阻断的特性或资源错误。通过 CPU 资源验证可尝试实验性应用，着色器编译、GPU 初始化和实际可见播放仍须运行时确认。视频仍是主要运行时目标。样本 `3337606455`（Shine）、`3258032485`（Shake）和原始默认 `3659880761` 已在所记录的单输出机器上通过真实 Tauri UI 应用/关闭隐藏/重启恢复/清除流程。365 默认流程另通过 Settings 15 → 30 FPS 与新进程偏好恢复，英/中文截图已阅；原生属性编辑、真实保存失败回滚/重试、新进程控件恢复、完整重置和十二秒自有全屏恢复也已通过；遮挡 callback/暂停未测量，真实休眠/锁屏仍未验证，engine-only Probe 单独记录，详见[验收记录](../contributing/guide.md#2026-10-10-开发记录)。原引擎视觉 A/B 与日用验收仍未完成。

引擎按每输出截止时间调度帧，在稳定静态或暂停 Scene 上停止持续 draw/swap/frame callback，并把跨输出、候选与回滚的逻辑 RGBA 纹理/帧缓冲和粒子 VBO 负载限制为 512 MiB；这不是实测 VRAM 上限。Settings 保存帧率和电池暂停偏好并更新运行中的引擎。隔离 15 → 30 FPS 服务测试测得每秒约 14.70 → 29.60 次完成 swap，后端和分配保留；有限原生 Settings/保存/重启及中文布局检查通过。新增混合 Scene Probe 在 30 FPS 上限下约 27.95 swap/s，暂停六十秒期间 draw/swap/callback 均为零，恢复后约 28.33 swap/s。实际电池转换、24 小时运行、真实休眠恢复、安装包与独立多显示器验收仍未完成。

历史 2026-10-10 只读 CPU 门控复跑通过 11 个原始包中的三个：`3258032485`、`3337606455` 和 `3659880761`。当时其余八个首项阻断于 SceneScript（五项）、相机、HDR 或图层数量，11 个原包哈希均与此前 inventory 一致。这是已记录编译产物的准备证据，不是原生 UI 或 Workshop 兼容率；此前通过两个的结果属于历史快照。此前 100 轮 Scene/视频生命周期测试通过，进程 RSS 同时上升。资源诊断指向分配器保留空闲空间这一来源，不证明全部原生内存无泄漏或 RSS 达到稳定上界。新增 20 轮 365/视频混合循环通过，未见 FD 累加，清除后的 Rust 活跃字节固定，但进程 RSS 与分配器保留仍显著。日用资源稳定性尚未验收，详见[资源后续记录](../contributing/guide.md#2026-10-10-开发记录)。

## 显示器分配

LWE 是桌面应用优先的产品。预期工作流是：

1. 从本地库选择内容；
2. 选择显示器；
3. 应用壁纸；
4. 需要时清除或替换分配。

显示器发现和恢复行为取决于 Linux 会话。已验证路径是 Wayland + `niri`；其他环境在写入支持文档前需要明确验证。LWE v1 不计划支持 X11 壁纸运行时。后续运行时扩展以 `wl_output`、`zwlr_layer_shell_v1` 等 Wayland 协议能力为中心，而不是桌面环境专属集成。

## 设置

设置用于管理用户偏好和集成状态：

- 语言；
- 主题；
- Steam Web API 密钥；
- 在支持环境中的开机启动行为；
- 壁纸帧率上限和电池暂停偏好；
- 可见的 Steam 集成状态。

设置属于用户可见产品界面，必须同时提供英文和简体中文。

帧率选择是上限，不保证实际呈现达到该帧率。播放设置会保存供下次启动使用，并发送给运行中的后端；实时更新问题表示已保存偏好可能与当前运行时不同。电池暂停保留手动暂停意图。所记录桌面的实际电池/交流电切换仍未验证。

## 数据和本地状态

对于通过资源门控的 Scene，在素材库详情中选择显示器，再打开“场景属性”。当前支持作者定义的开关、以数值输入框编辑的 slider 值、颜色和 combo 选择；slider 范围及步长来自项目，combo 值须属于作者声明选项。背景选择可通过受支持的 bool/combo 可见性绑定切换图层。

作者分组收纳其后控件，直到下一个分组；第一组前的控件不归组。可用鼠标、Enter 或空格展开／折叠分组，这只改变面板布局。分组标题不会作为壁纸值提交、发送给脚本或写入会话文件；切换壁纸或显示器时，折叠状态会重置。

编辑保持为草稿，直到“保存并应用”成功。面板只对本地评估可播放的 Scene 和已选显示器开放；分组布局不会使不受支持的 Scene 可播放。图片／视频替换、文字输入、选项显示条件表达式和用户快捷方式仍需各自资源与运行路径，仅添加输入控件不代表已支持这些能力。

LWE 在应用使用的 `lwe` 配置根目录保存状态。Scene 属性按壁纸项目和显示器分别保存，与分配位于同一会话文件；普通替换或清除保留这些选择，重置选择恢复项目默认值。

作者声明更新后，若已保存选择失效，可从属性加载错误状态点击重置默认值；它通过同一资源门控应用受支持默认值，移除对应项目/显示器选择，普通保存仍需经验证的属性快照。开发中的“保存并应用”路径在准备、第一帧接纳和原子保存成功后保留新值；持久发布前的准备、候选接纳或保存失败保留原壁纸、已保存选择和编辑草稿，候选音频在 Finalize 前保持静音。原生保存并应用、真实写入失败重试、新进程属性恢复和重置默认值已在隔离配置下通过；重置恢复全部作者默认值并保留分配，普通清除保留已保存选择。原版 A/B、硬件功耗/锁屏/休眠和日用验收仍未完成。

## 当前限制

首发版本不以以下能力为目标：

- 完整网页壁纸运行时兼容；
- 创作者工具；
- 云或社区系统；
- 高级自动化规则；
- 对未测试合成器或桌面环境的保证行为；
- X11 壁纸运行时支持。
